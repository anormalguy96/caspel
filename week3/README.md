## Questions' answer one by one

### What is LLM

LLM stands for Large Language Model. It's a type of AI model that's trained on a massive dataset of text data to understand and generate human language.

### What is token

A basic unit of text that's used by LLMs. It can be a word, a part of a word, or a punctuation mark.

### Context window

The maximum number of tokens that an LLM can process at once. It's usually measured in tokens.

### Temperature

The parameter that controls the randomness of an LLM's output. It is usually measured in tokens.

### Hallucination

Hallucination is a phenomenon in which an LLM generates false or nonsensical information.

### System prompt vs user prompt

- **System prompt:** Instructions given to an LLM to control its behavior.
- **User prompt:** A prompt that is given to an LLM to generate a response.
